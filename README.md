# 🧵 FabricHub – Fabric Marketplace

FabricHub is a full-stack online marketplace built with Next.js that connects fabric suppliers with buyers. Suppliers can showcase and sell their fabrics, while buyers can browse products, view details, and purchase fabrics through an easy-to-use marketplace interface.

##  Features

### Buyer
- Browse available fabrics
- Search and filter products
- View detailed product information
- Add products to cart
- Manage cart items
- Place orders
- Manage profile and orders

### Supplier
- Supplier registration and login
- Create and manage product listings
- Upload fabric/product details
- Manage inventory
- View and manage orders
- Manage supplier profile

###  Authentication
- Secure user authentication
- Role-based access for Buyers and Suppliers
- Protected routes and user-specific functionality

## Tech Stack

- **Frontend:** Next.js, React, JavaScript
- **Styling:** CSS / Tailwind CSS
- **Backend:** Next.js API Routes
- **Database:** MongoDB 
- **Authentication:** JWT
- **Deployment:** Vercel
